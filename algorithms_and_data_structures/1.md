## 1. Алгоритм, свойства алгоритма, способы описания алгоритма, алгоритмические структуры (типы алгоритмов), шаблон описания алгоритма, этапы решения задач на ПК.

- Алгоритм (от имени среднеазиатского математика Аль-Хорезми) - конечная совокупность точно заданных правил решения некоторого класса задач или набор инструкций, описывающих порядок действий исполнителя для решения определенной задачи.

### Свойства алгоритмов:

1. Универсальность - применимость к широкому спектру задач
2. Дискретность - алгоритм должен быть разбит на отдельные, четко определенные шаги или операции.
3. Конечность - процесс решения задачи не может продолжаться бесконечно.
4. Результативность - должен приводить к получению корректного результата для всех возможных входных данных.
5. Выполнимость (эффективность) - время выполнения алгоритма должно быть ограниченным и приемлемым для решения конкретной задачи
6. Детерминированность - для одного и того же входа алгоритм всегда должен выдавать одинаковый результат.
7. Последовательность - шаги алгоритма должны выполняться в строго определенной последовательности.
