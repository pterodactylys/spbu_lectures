## 5. Уровни представления данных, абстрактный тип данных, классификация структур данных, операции над струткурами данных.

### Уровни представления данных
* Информация в компьютере представляется человеку в каком-то виде (в абстрактном виде), который на его взгляд упорядочивает данные и придает им смысл.
* Компьютер отводит поле для поступающей информации и задает какой-то адрес хранения.

Человек обрабатывает данные на логическом уровне (абстрактно), компьютер обрабатывает данные на физическом уровне.

### Абстрактный тип данных
- это набор, включающий данные и выполняемые над ними операции, набор данных и методов, служащих одной цели.
- это тип данных, который предоставляет для работы с элементами этого тиап определенный набор функций, а также возможность создавать элементы такого типа при помощи специальных функций.

Примеры: очередь, список, стек, дек.

### Классификация структур данных:
- Простые - структуры данных, которые не могут быть разделены на составные части, большие чем бит. С точки зрения физической структуры, в данной системе программирования всегда можно заранее сказать какой будет размер данного простого типа и какова его структура размещения в памяти. С логической точки зрения простые данные являются неделимыми единицами.
- Интегрированные - структуры данных, составными частями которых являются другие структуры данных (простые или в свою очередь интегрированные). Интегрированные структуры данных конструируются программистом с использованием средств интеграции данных, предоставляемых языками программирования.

В зависимости от отсутствия или наличия явно заданным связей между элементами данных следует различать:
* Несвязные структуры (векторы, массивы, строки, стеки, очереди)
* Связные струкуры (связные списки)

Структуры данных по принципу изменчивости (изменение числа элементов):
* статические (массив)
* полустатические (вектор)
* динамические (списки, очередь, деревья, дек, стек)

### Операции над структурами данных

Операции обязательные для всех структур и типов данных (выполянются над любыми структурами данных): создание, уничтожение, выбор, обновление.

Для каждой структуры могут быть определены специфические операции, работающие только с данной структурой.
* Создание - выделение памяти для структуры данных в процессе выполнения программы или на этапе компиляции. Программист может сам выделять память, если захочет.
* Уничтожение
* Выбор - операция доступа к данным внутри самой структуры.
* Обновление - изменение щначения данных в структуре данных (присваивание, передача параметров).
