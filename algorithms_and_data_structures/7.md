## 7. Записи, их хранение, операции над записями

- Запись - совокупность ограниченного числа логических связных компонентов, принадлежащих к разным типам.

Компоненты записи называются полями, каждое из которых определяется именем.
- Мощность составляющего типа - произведение мощностей составляющих его типов.

Каждый элемент записи имеет уникальное для этой записи имя. (т.е. такое же имя может встречаться только в другой таблице)

Записи как и массивы состоят из фиксированного числа элементов, но между ними имеются несколько различий:
1. В отличие от массивов где данные состоят из фиксированного числа элементов, элементы записи могут быть разных типов.
2. В массивах доступ к элементам осуществялется по индексам, а в записях по именам. Отдельные поля записи могут служить в качестве ключей записи.

Записи используют в структурах:
1. В таблицах
2. В файлах
3. В базах данных

### Хранение записи
Запись хранится в одной сплошной области памяти. Причем ее жлементы располагаются в памяти последовательно друг за другом, в том порядке в котором оги перечислены в записи.

### Операции над записями:
1. Важнейшей операцией для записи является операция доступа к выбранной записи. (операция квалификации)
Над выбранным полем допустимы любые операции допустимые для типа данного поля.

2. Операция присваивиния - одной записи присваиваем запись, состоящую из тех же типов.
3. Операция сравнения - записи, состящие из одних и тех же типов, можно сравнить. (в некоторых языках это можно сделать только поэлементно).\
